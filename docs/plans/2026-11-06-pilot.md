# PMV 引擎试点计划

- 2026-11-06 建立。负责人：Cursor 会话「四人乐队PMV视频效果分析」，兼任导演和设计侧。
- 当前状态：计划已定，等用户提供歌曲音频。W1 不依赖歌曲，可以先做。

## 目标

做一个通用的动画 PMV 引擎：输入一首歌和一组角色设定，产出角色在动、动作卡在拍子上的 1080p 成片。引擎做成 CLI 加 Skill，换歌、换角色只改项目数据，不改引擎代码。

## 背景

- 上次 macair `ai-band-pv` 的两版成片像"PPT 加配乐"：镜头内角色不动，镜头内相邻帧变化像素占比的中位数分别是 3.4% 和 0.0%；音乐是无人声的合成器乐；自检只看静帧。
- 原方案靠视频 API 生成镜头片段。用户 11-06 改为不生成视频，参照 `next-token-pmv` 的做法：原画切换加 2.5D 视差。

## 关键决定（11-06 用户确认）

| 项 | 决定 |
| --- | --- |
| 画面动作 | 不用视频生成。表演镜头在重拍上切换同机位的 2–4 张原画，做有限动画；运镜用深度视差，即 2.5D 多层摄影台；光效、粒子、歌词用 Remotion 代码做 |

| 歌 | 用户提供有授权的成品歌。音频和人声分轨不进 git |

| 仓库 | 本仓库，GitHub `ump45nose/pmv-engine`，私有 |
| 与 next-token-pmv | 两条线：只借鉴做法，不共享代码，不改它的文件 |

## 流程

```
歌曲 → ① analyze：song.json（BPM、拍、重拍、小节、段落、歌词时间轴）
     → ② 导演：shots.json（每镜的小节区间、角色、景别、基准帧、姿势差分和切换节奏、运镜、特效、歌词）
     → ③ art：基准帧 → 姿势差分 → 深度图；先出动态分镜 ◀ 人审 1
     → ④ render：Remotion 按 song.json 和 shots.json 合成，音轨用原曲
     → ⑤ qa：运动、卡点、一致性、静止时长 → 导演出修改单 ◀ 人审 2
```

一个镜头大致长这样，字段在 W1 定稿：

```json
{ "id": "C1-03", "bars": [33, 35], "section": "chorus", "characters": ["gpt"],
  "framing": "medium", "base": "drums, both sticks raised before the hit",
  "poses": [{ "id": "a", "edit": null }, { "id": "b", "edit": "sticks down on the snare, hair bounces" }],
  "switch": { "on": "beat", "pattern": ["a", "b"] },
  "camera": { "move": "push", "depth": 0.6 }, "fx": ["flash@downbeat"] }
```

## 引擎结构

- CLI 子命令 `analyze`、`art`、`animatic`、`render`、`qa`。每步读写项目目录里的文件，输出 JSON 和下一步提示。
- 项目目录：`song/`、`bible/`（角色参考图和锁定描述）、`shots.json`、`art/`、`out/`、`jobs.jsonl`。引擎仓库里只放示例项目的非媒体文件。
- Remotion 模板只读 `song.json` 和 `shots.json`，不写死任何一首歌或角色。
- 生图适配层：每个 worker 用独立缓存目录，避开 codex-cli 的全局锁；每次生成记进 `jobs.jsonl`（参数哈希、耗时、结果），同样的参数不重复生成；生图中转会话用够用的最低 effort。

## 试点（20–30 秒副歌）

- 角色沿用四人乐队：GPT、Claude、Gemini、DeepSeek 娘，参考图用公开设定图。
- W1 引擎骨架：数据格式、CLI、`analyze`，以及 `qa` 的运动和卡点指标（移植上次的 `motion_stats.py`）。用合成的节拍音轨自测，不依赖歌曲。
- W2 生图：基准帧、姿势差分、深度图，输出动态分镜。之后人审 1。
- W3 合成：Remotion 模板（视差运镜、原画切换、光效、歌词）和渲染。
- W4 质检与修改：qa 报告、审片、修改单、重渲染。之后人审 2。
- 试点通过后：做整首歌；整理成 Skill；换一首歌和一组角色，验证通用性。

## 验收标准（试点）

- 运动：表演镜头每小节至少切换 2 次原画；除刻意定格外，画面完全静止不超过 1 秒；镜头内运动指标明显高于上次两版，阈值在 W1 用上次成片做对照定下。
- 卡点：切镜和原画切换落在拍点 ±2 帧内。
- 一致性：同一镜头的姿势差分之间，脸、服装、乐器、背景没有明显跳变；审片通过，并经用户确认。
- 输出：1080p、24 fps，音轨与原曲一致。
- 成本：付费支出 ≤ $30；Codex 生图额度逐次记账。

## 风险

- 姿势差分走样：编辑基准帧时可能改了脸或背景。试点先测 3 个镜头；不行就改为角色和背景分开生成，再合成。
- 手和乐器容易崩：避开手部大特写，或者局部重绘。
- Codex 额度紧：11-06 21:20 已用 89%，11-11 15:07 重置，和 next-token-pmv 共用。试点约需 30–40 张图。
